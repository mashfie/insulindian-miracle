# Methodology

The project is best understood as a layered approximation:

1. a spatial political-economy simulator on a stylized peninsula,
2. a sequential allocation problem over stateful arms,
3. a comparison set of stationary, forgetting, contextual, and restless heuristics.

## Methodological stance

- The simulation is reduced-form, not structurally estimated.
- The scenario analogies are literature-backed but stylized.
- The exact environment is not a classical stationary MAB and not a provably indexable RMAB.
- Evaluation currently mixes code-grounded metrics with a partial results archive; provenance must be made explicit whenever empirical claims are stated.
