# Institutional Economics

The wiki uses institutional-economics language to interpret three site-level state variables:

- extraction,
- openness,
- adaptability.

## Literature spine

- [Acemoglu, Johnson, and Robinson (2001)](https://www.nber.org/papers/w8460)
- [Acemoglu, Johnson, and Robinson (2005)](https://www.nber.org/papers/w10481)

These papers motivate two claims relevant here:

1. institutions have persistent causal consequences,
2. institutional change is tied to political power and shocks, not only to technology or geography.

## Mapping to the code

The code compresses a broad institutional domain into three continuous coordinates plus a shock legacy term. That is a reduced-form state representation, not a structural institutional model.

## Why this still matters

Even in reduced form, the simulator can ask coherent comparative questions:

- what happens when resource rents meet weak institutional buffers?
- when do shocks create reform windows rather than deeper lock-in?
- how much does policy quality matter when institutions are already strong?
