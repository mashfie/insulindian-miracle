# GitHub About Copy

## Short Description

Computational political-economy sandbox for city formation on generated peninsulas, using bandit policies to study institutional drift and the resource curse.

## Longer Blurb

Insulindian Miracle is a research-oriented simulation toolkit for testing how geography, institutions, and learning policies interact during city formation. It models settlement choice as a non-stationary bandit problem with resource rents, institutional drift, reforms, shocks, and network effects.
