# Open Cluster

## Mechanism

This scenario injects a pro-trade cluster treatment.

Key overrides:

- higher initial openness,
- larger network scale and network gains,
- lower congestion,
- explicit trade-cluster count, radius, and bonuses.

## Literature analogue

- [Krugman (1991)](https://www.nber.org/papers/w3275)
- [Duranton and Puga (2004)](https://www.sciencedirect.com/science/article/pii/S1574008004800051)

The scenario encodes sharing, matching, and network access in reduced form.

## Expected signatures

- stronger cluster premium,
- more durable secondary-city outcomes than baseline,
- improved relative performance of state-aware and contextual policies.
