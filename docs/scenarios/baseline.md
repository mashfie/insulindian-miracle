# Baseline

## Role

`baseline` is the control scenario: `SimulationConfig::default()` with no overrides.

## Mechanism

It keeps:

- moderate resource payoffs,
- moderate curse pressure,
- no boomtown,
- no trade-cluster treatment,
- no exogenous shock regime.

## Use

This is the cleanest setting for reading the raw geometry of the reward law before scenario perturbations.
