# Balanced Urban

## Mechanism

Config source: `configs/scenarios/balanced-urban-system.json`.

The scenario is tuned toward durable midsize-city coexistence.

Key overrides:

- larger `secondary_city_bonus`,
- broader `secondary_city_spread`,
- gentler metropolitan penalty,
- stronger network capital and density gains,
- moderately stronger inclusive productivity.

## Expected signatures

- weaker primacy than [[megacity-trap]],
- more support for secondary centers,
- Zipf slopes closer to the empirical corridor than the baseline extremes.
