# Python Analysis Pipeline for Insulindian Miracle

This directory contains the downstream research shell for the Insulindian Miracle project, built in Python. It provides feature parity with the R analysis pipeline, focused on analyzing the Parquet and JSON artifacts generated by the Rust engine.

## Prerequisites

You will need Python 3.9+ installed along with the following packages:
```bash
pip install pandas numpy pyarrow matplotlib seaborn scikit-learn
```

## Structure

*   `01_load_data.py`: Functions to load and preprocess Parquet and JSON outputs from the Rust engine.
*   `02_regret_analysis.py`: Computes policy regret relative to the `myopic-oracle` or optimal policies.
*   `03_clustering_pca.py`: Performs Principal Component Analysis (PCA) and k-means clustering on the simulation outcomes.
*   `04_phase_maps.py`: Generates phase transition maps across parameter sweeps (requires sweep data).
*   `05_figures.py`: Publication-grade matplotlib/seaborn figures for visualizing policy performance and spatial outcomes.

## Usage

These modules can be imported into your Jupyter Notebooks or run sequentially. The expected input data should reside in the `results/` directory. Note that the scripts are prefixed with numbers; import them using `importlib` or by running them directly as scripts.
