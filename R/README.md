# R Analysis Pipeline for Insulindian Miracle

This directory contains the downstream research shell for the Insulindian Miracle project, focused on analyzing the Parquet and JSON artifacts generated by the Rust engine.

## Prerequisites

You will need R installed along with the following packages:
```R
install.packages(c("arrow", "dplyr", "ggplot2", "jsonlite", "tidyr", "readr", "stringr", "factoextra", "cluster"))
```

## Structure

*   `01_load_data.R`: Functions to load and preprocess Parquet and JSON outputs from the Rust engine.
*   `02_regret_analysis.R`: Computes policy regret relative to the `myopic-oracle` or optimal policies.
*   `03_clustering_pca.R`: Performs Principal Component Analysis (PCA) and k-means clustering on the simulation outcomes to identify regime shifts and world topologies.
*   `04_phase_maps.R`: Generates phase transition maps across parameter sweeps (requires sweep data).
*   `05_figures.R`: Publication-grade ggplot2 figures for visualizing policy performance, gini coefficients, and spatial outcomes.

## Usage

Source the scripts sequentially or use them as a library in your own analysis notebooks. The expected input data should reside in the `results/` directory (e.g., `results/high/`, `results/low/`, `results/manifests/`).
